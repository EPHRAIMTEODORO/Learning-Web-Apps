# AI Reflection

## What did you ask the AI to do?

I asked AI to create prompts for me and to explain what EJS is and how it works, kind of like a guide. I also asked AI to add the three additional features: a 404 page, a dynamic route, and EJS partials.

## What did it do well?

It did well on making the new pages have the same style as the other pages. It also did well in giving page suggestions and explaining topics like middleware and partials.


## What did it get wrong or what did you have to fix?

It did not really get it wrong, but it more so misinterpreted my prompt. I had to explicitly give instructions on where the files I needed were found. I also had to make some minor fixes when the CSS did not render during testing.


## What did you learn from the AI suggestions?

I learned what EJS is. It is kind of similar to PHP or the Ruby on Rails framework for me. I also learned how Express middleware follows an order, so the error page should be last. I also learned about partials, which remind me of Ruby on Rails concepts.
