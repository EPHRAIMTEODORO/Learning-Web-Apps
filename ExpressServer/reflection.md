# AI Reflection

## What did you ask the AI to do?

I asked AI to generate appropriate prompts for me. This included a prompt for improving the website and a prompt for making changes according to what I wanted by having the AI explicitly ask me about each feature I wanted. I also used AI for Markdown syntax in the README and `reflection.md`.

## What did it do well?

It did well in getting linked images for the website I made and integrating the UI changes that I wanted.


## What did it get wrong or what did you have to fix?

The first design was not my type, so I used AI to generate a prompt for UI improvements. Then I added what kind of improvements I wanted before giving the prompt to AI again.


## What did you learn from the AI suggestions?

AI suggestions are based on what is most commonly used on the internet or in its database, so if you have a certain design in mind, you need to be able to create a good prompt so AI can do it. I also learned AI is good for prototyping, but ultimately it still needs humans for creativity and purpose.
